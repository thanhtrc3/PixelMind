## Quy ước chung (áp dụng cho MỌI task)

**Cấu trúc:** Electron main (`electron/main/`) — preload (`electron/preload/index.ts`) — renderer React (`src/`) — hợp đồng chung (`shared/`). Alias: `@shared/*` → `shared/*`, `@/*` → `src/*`.

**Luật cứng:**

1. **Thêm một API mới phải sửa đủ 3 chỗ**, nếu thiếu `npm run typecheck` sẽ đỏ:
   - `shared/api.ts` → khai báo trong `interface PixelMindApi`
   - `electron/preload/index.ts` → cài đặt bằng `ipcRenderer.invoke(...)`
   - `src/lib/mock.ts` → cài đặt giả lập trong `createBrowserMock()` (trả về `PixelMindApi`, TS bắt buộc đủ thành viên)
   - Và `electron/main/index.ts` → `ipcMain.handle('<channel>', ...)`.
2. **Module nào cần unit-test thì KHÔNG được `import ... from 'electron'`.** Các module hiện có đã theo luật này (`runnerPorts.ts`, `styleSync.ts`, `toolbox.ts`, `customParts.ts`). Nếu cần `safeStorage`/`app`, tách phần thuần (pure) ra file riêng rồi bọc ở `index.ts`.
3. **Test chạy bằng Node, import thẳng file `.ts`:**
   `node --experimental-strip-types --test tests/<ten>.test.mjs`
   Cú pháp file test: `import test from 'node:test'` hoặc `import { describe, it } from 'node:test'` (repo dùng cả hai). Assert: `node:assert/strict`.
   Test mới phải được thêm vào chuỗi lệnh `"test"` trong `package.json` (script liệt kê từng file, không dùng glob).
4. **Chuỗi UI viết tiếng Việt**, không dấu ngoặc lạ, theo giọng hiện có ("Hãy…", "Không…").
5. **Không thêm dependency mới**, ngoại lệ duy nhất: `axe-core` (devDependency) ở plan D1-19.
6. **Gọi mạng/CLI phải có timeout và thông báo lỗi cụ thể** — không được `catch {}` im lặng ở luồng người dùng.
7. **Mỗi task kết thúc bằng commit** theo kiểu hiện có: `feat(scope): mo ta ngan (D1-xx)`. Không commit file `.env`, không in token/secret ra log.
8. **Xong mỗi task chạy:** `npm run typecheck` + đúng file test của task. Xong cả plan chạy: `npm test` và `npm run build`.

**Trạng thái hiện tại của repo:** có thay đổi chưa commit ở nhánh `main` (custom parts). Trước khi bắt đầu, chạy `git status` và commit/tách nhánh `feat/<ten>` để không trộn thay đổi.

**Định dạng code trong plan:** mọi snippet là *hợp đồng* (tên, tham số, kiểu trả về, giá trị cụ thể). Người thi hành viết thân hàm; chỉ chép nguyên văn khi plan ghi "chép nguyên văn".

## Kiểm thử sau khi cả bộ xong (người review chạy)

Chi tiết đầy đủ theo từng bề mặt (backend, IPC, UI, dữ liệu, bảo mật, lỗi, hồi quy) nằm ở
**[2026-11-18-test-plan.md](./2026-11-18-test-plan.md)** — dùng file đó, không dùng danh sách ngắn dưới đây.

```powershell
npm run typecheck
npm test
npm run build
npm run check:api   # preload ↔ main: channel thiếu handler / thiếu sender
```

Sau đó làm theo mục **"Nghiệm thu thủ công"** ở từng plan; ghi lại bằng chứng (ảnh chụp/đoạn log) vào mô tả PR. Không tuyên bố "đã xong" nếu chưa chạy các bước đó.
