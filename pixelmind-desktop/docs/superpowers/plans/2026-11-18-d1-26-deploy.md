# D1-26 — Deploy / Preview URL — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`).

**Goal:** Người dùng cấu hình lệnh deploy (Vercel/Netlify/CLI tuỳ ý) + token lưu mã hoá; bấm Triển khai thấy tiến trình log theo thời gian thực; lỗi CLI/network hiện cụ thể; URL deploy được lưu vào dự án. Token **không bao giờ** xuất hiện trong log, trong câu lệnh, hay gửi xuống renderer.

**Architecture:** `electron/main/deploy.ts` (không import `electron`) spawn lệnh, che secret, bắt URL. `index.ts` giữ token qua `secretStore` (safeStorage) và phát `deploy:log` / `deploy:state`. Renderer chỉ thấy log đã che + URL.

**Tech Stack:** node:child_process, Electron `safeStorage`, IPC, React, node:test.

**Spec:** `pixelmind-feature-checklist-2dev.md:115` (D1-26).

## Global Constraints

- Token chỉ truyền qua **biến môi trường** của tiến trình con. Không nối token vào chuỗi lệnh.
- Mọi dòng log (stdout/stderr/system) phải đi qua `redactSecrets` **trước khi** gửi IPC hoặc ghi file.
- Không có `safeStorage` khả dụng → **không** lưu token (báo người dùng nhập lại mỗi lần), tuyệt đối không ghi plaintext.
- Timeout mặc định 5 phút, có thể truyền `timeoutMs` để test.
- `deploy.ts` không import `electron` (test trực tiếp).
- Mirror API 3 chỗ: `shared/api.ts`, `electron/preload/index.ts`, `src/lib/mock.ts`.

## Review Focus

- Token xuất hiện trong stdout của CLI (một số CLI in header Authorization) → log hiển thị `***`.
- Lệnh không tồn tại / thoát mã ≠ 0 → thông báo nêu mã lỗi + 8 dòng stderr cuối đã che secret.
- Treo quá timeout → kill tiến trình và báo lỗi, không để dialog quay mãi.
- Deploy lần 2 → URL mới ghi đè URL cũ trong project meta.
- Đóng dialog khi đang deploy → tiến trình vẫn kết thúc/không crash main; renderer unsubscribe sạch.

- [ ] **Step 1: Viết test đỏ**

Thêm vào `tests/deploy.test.mjs` (import `mkdtemp`, `writeFile` từ `node:fs/promises`, `tmpdir`, `join`):

```js
import { mkdtemp, writeFile } from 'node:fs/promises'
import { tmpdir } from 'node:os'
import { join } from 'node:path'
import { runDeployCommand } from '../electron/main/deploy.ts'

const TOKEN = 'super-secret-token-999'

async function makeScript(body) {
  const dir = await mkdtemp(join(tmpdir(), 'pm-deploy-'))
  const file = join(dir, 'deploy.mjs')
  await writeFile(file, body, 'utf8')
  return { dir, command: `node "${file}"` }
}

describe('runDeployCommand', () => {
  it('phát log đã che secret, bắt URL và ok=true', async () => {
    const { dir, command } = await makeScript(
      "console.log('token=' + process.env.PM_TOKEN)\nconsole.log('Production: https://demo.vercel.app')\n",
    )
    const logs = []
    const res = await runDeployCommand({
      command, cwd: dir, env: { PM_TOKEN: TOKEN }, secrets: [TOKEN], onLog: (l) => logs.push(l),
    })
    assert.equal(res.ok, true)
    assert.equal(res.url, 'https://demo.vercel.app')
    assert.ok(logs.length > 0)
    const joined = logs.map((l) => l.text).join('')
    assert.doesNotMatch(joined, new RegExp(TOKEN))
    assert.match(joined, /\*\*\*/)
  })

  it('thoát mã khác 0 trả lỗi kèm stderr đã che', async () => {
    const { dir, command } = await makeScript(
      "console.log(process.env.PM_TOKEN)\nconsole.error('build failed: missing module')\nprocess.exit(2)\n",
    )
    const res = await runDeployCommand({ command, cwd: dir, env: { PM_TOKEN: TOKEN }, secrets: [TOKEN] })
    assert.equal(res.ok, false)
    assert.match(res.error, /mã 2/)
    assert.match(res.error, /missing module/)
    assert.doesNotMatch(res.error, new RegExp(TOKEN))
  })

  it('quá timeout thì kill và báo lỗi', async () => {
    const { dir, command } = await makeScript('setTimeout(() => {}, 5000)\n')
    const started = Date.now()
    const res = await runDeployCommand({ command, cwd: dir, timeoutMs: 300 })
    assert.equal(res.ok, false)
    assert.match(res.error, /thời gian/i)
    assert.ok(Date.now() - started < 4000)
  })

  it('lệnh không tồn tại trả lỗi cụ thể', async () => {
    const { dir } = await makeScript('')
    const res = await runDeployCommand({ command: 'pm-lenh-khong-ton-tai-xyz', cwd: dir })
    assert.equal(res.ok, false)
    assert.ok(res.error && res.error.length > 10)
    assert.match(res.error.toLowerCase(), /pm-lenh-khong-ton-tai-xyz|không khởi chạy/)
  })
})
```

- [ ] **Step 3: Cài đặt `electron/main/deploy.ts`**

Dùng `spawn` với `{ shell: true, cwd, env: { ...process.env, ...env }, windowsHide: true }`.

Hành vi bắt buộc:

1. `onLog` được gọi cho mỗi chunk dòng: `{ at: Date.now(), stream, text: redactSecrets(chunk, secrets) }`. Gộp buffer theo `\n`, flush phần dư khi kết thúc.
2. `stdoutText` tích luỹ (đã che) để `parseDeployUrl` sau cùng; `stderrLines` giữ tối đa 40 dòng cuối (đã che).
3. Timeout (`timeoutMs ?? 300_000`): `setTimeout` → `child.kill()`; đánh dấu `timedOut = true`; onLog system `'[system] Quá thời gian triển khai, đã dừng tiến trình.\n'`.
4. `close`:
   - `timedOut` → `{ ok:false, url:null, code, error: 'Quá thời gian triển khai (quá ${Math.round(timeoutMs/1000)} giây). Kiểm tra kết nối mạng hoặc lệnh deploy.' }`
   - `code === 0` → `{ ok:true, url: parseDeployUrl(stdoutText), code: 0 }` (URL null vẫn ok, UI báo "Không tìm thấy URL trong output").
   - còn lại → `{ ok:false, url:null, code, error: deployErrorMessage(code, stderrLines.join('\n')) }`.
5. `error` event (spawn fail) → clearTimeout, `{ ok:false, url:null, code:null, error: deployErrorMessage(null, '') + ' ' + message }`.
6. Không bao giờ `throw`.

1. `npm run dev` → Cài đặt → **Triển khai** → lệnh:
   `node -e "console.log('token=' + process.env.PM_TOKEN); console.log('Production: https://demo-vercel.vercel.app')"`, tên biến `PM_TOKEN`, lưu token `bi-mat-123456`.
2. Mở dự án → menu **Công cụ → Triển khai / Preview URL** → **Triển khai ngay**.

4. Đóng/mở lại dialog → "Lần triển khai trước" hiện đúng URL (đã lưu vào project meta).

6. Đổi lệnh thành `node -e "setTimeout(()=>{}, 400000)"` → chờ timeout 5 phút hoặc tạm đổi `timeoutMs` để kiểm tra: báo quá thời gian, tiến trình bị kill.
