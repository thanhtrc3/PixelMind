# D1-21 — Mock API cho dự án thử nghiệm — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`).

**Goal:** Cấu hình danh sách route (method + path + status + JSON body) theo dự án, bật/tắt một HTTP server cục bộ có kiểm soát cổng; frontend của dự án gọi đúng status/body; dừng server giải phóng cổng.

**Architecture:** Module thuần Node `electron/main/mockApi.ts` (không import `electron`) chạy `node:http`, dùng lại `isPortAvailable` từ `runnerPorts.ts`. `index.ts` giữ một instance singleton, phát sự kiện `mock:state` cho renderer. Cấu hình lưu tại `<project>/.pixelmind/mock.json`.

**Tech Stack:** node:http, Electron IPC, React, node:test.

**Spec:** `pixelmind-feature-checklist-2dev.md:107` (D1-21).

## Global Constraints

- Server chỉ bind `127.0.0.1` (không mở ra LAN).
- Cổng: `port = 0` → OS tự chọn và trả cổng thật; `port > 0` mà bị chiếm → trả lỗi rõ ràng, **không** tự đổi cổng.
- Mọi response có `Access-Control-Allow-Origin: *` + xử lý `OPTIONS` 204 (frontend dev server khác origin gọi được).
- Stop phải đóng cả keep-alive socket rồi mới resolve (nếu không Windows giữ cổng).
- `mockApi.ts` không import `electron`; test chạy trực tiếp bằng Node.
- Mirror API 3 chỗ: `shared/api.ts`, `electron/preload/index.ts`, `src/lib/mock.ts`.

## Review Focus

- Bấm Stop rồi Start lại ngay → phải bind lại được (cổng đã nhả).
- `port` bị chiếm bởi app khác → thông báo nêu đúng số cổng, không crash main process.
- Route `/api/x` khi request `/api/x?q=1` phải khớp.
- Body JSON hỏng trong cấu hình → báo lỗi validate, không làm sập server.
- Request không khớp route → 404 JSON, không treo kết nối.

- [ ] **Step 3: Cài đặt `shared/mockApi.ts`**

Quy tắc normalize:
- `port`: `Number(...)`; hợp lệ 0..65535 (0 = auto), nguyên; nếu không → lỗi `'Cổng phải là số nguyên từ 0 đến 65535.'` và dùng 0.
- mỗi route: `method` upper + phải nằm trong `MOCK_METHODS` (mặc định GET + lỗi), `path` qua `normalizeMockPath` (rỗng → '/' + lỗi nếu không bắt đầu bằng '/'), `status` 100..599, `body` rỗng hoặc `JSON.parse` thành công, `delayMs` 0..5000, `id` = `String(raw.id || 'r_' + index)`.
- sai → push message dạng `Route #${index + 1}: <lý do>.` (không throw).
- `matchMockRoute` so `method.toUpperCase()` và `normalizeMockPath(pathname)`.

`normalizeMockPath`:
```ts
export function normalizeMockPath(value: string): string {
  const clean = String(value || '').trim().split('?')[0].split('#')[0]
  if (!clean) return '/'
  const withSlash = clean.startsWith('/') ? clean : `/${clean}`
  return withSlash.length > 1 ? withSlash.replace(/\/+$/, '') || '/' : '/'
}
```

import { MockApiServer } from '../electron/main/mockApi.ts'
import { isPortAvailable } from '../electron/main/runnerPorts.ts'

const config = {
  port: 0,
  routes: [
    { id: 'hello', method: 'GET', path: '/api/hello', status: 201, body: '{"hello":"world"}' },
    { id: 'echo', method: 'POST', path: '/api/echo', status: 200, body: '{"ok":true}' },

describe('MockApiServer', () => {
  it('phục vụ đúng method/status/body rồi dừng giải phóng cổng', async () => {
    const server = new MockApiServer()
    const started = await server.start(config)
    assert.equal(started.running, true)
    assert.ok(started.port > 0)
    const base = `http://127.0.0.1:${started.port}`

    const res = await fetch(`${base}/api/hello`)
    assert.equal(res.status, 201)
    assert.deepEqual(await res.json(), { hello: 'world' })
    assert.equal(res.headers.get('access-control-allow-origin'), '*')

    const post = await fetch(`${base}/api/echo`, { method: 'POST' })
    assert.equal(post.status, 200)
    assert.deepEqual(await post.json(), { ok: true })

    const missing = await fetch(`${base}/api/nope`)
    assert.equal(missing.status, 404)

    const options = await fetch(`${base}/api/hello`, { method: 'OPTIONS' })
    assert.equal(options.status, 204)

    assert.equal(started.calls.length >= 4, true)

    const stopped = await server.stop()
    assert.equal(stopped.running, false)
    assert.equal(await isPortAvailable(started.port), true)
    await assert.rejects(fetch(`${base}/api/hello`))
  })

  it('báo lỗi khi cổng bị chiếm, không đổi cổng', async () => {
    const server = new MockApiServer({ isPortAvailable: async () => false })
    const state = await server.start({ ...config, port: 4321 })
    assert.equal(state.running, false)
    assert.match(state.error, /4321/)
    assert.equal(state.port, null)
  })

   - `const route = matchMockRoute(this.routes, req.method || 'GET', pathname)`.

ipcMain.handle('mock:save', async (_e, projectPath: string, config: MockApiConfig) => {

  if (state.running) await writeMockConfig(projectPath, safe).catch(() => undefined)

## Nghiệm thu thủ công (D1-21)

1. `npm run dev` → mở dự án → menu **Công cụ → Mock API** → Cổng `4500`, thêm route `GET /api/hello`, status `201`, body `{"hello":"world"}` → **Lưu** → **Khởi động**.
2. Terminal: `curl.exe -i http://127.0.0.1:4500/api/hello` → `HTTP/1.1 201`, body đúng JSON, có header CORS.
3. Trong frontend dự án, gọi `fetch('http://127.0.0.1:4500/api/hello')` (hoặc dán URL vào address bar preview) → nhận đúng status/body.
4. Bấm **Dừng** → `curl` báo connection refused; `netstat -ano | findstr :4500` không còn listener.
5. Đặt cổng đang bận (ví dụ cổng của dev server) → **Khởi động** → thấy thông báo nêu đúng số cổng, không có server nào chạy.

- Không hỗ trợ path param/regex, không proxy, không GraphQL, không auth cho mock, không HTTPS.
