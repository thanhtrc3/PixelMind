# D1-19 — Accessibility Checker (axe-core) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`).

**Goal:** Chạy axe-core trên đúng DOM của trang preview đang mở, nhóm lỗi theo mức độ, hiển thị selector + hướng dẫn; khi không chạm được vào DOM thì báo rõ trạng thái thay vì "không có lỗi".

**Architecture:** Renderer đóng gói source `axe.min.js` (Vite `?raw`), gửi qua IPC. Main process chọn đúng frame preview trong `mainWindow.webContents.mainFrame.frames`, inject source bằng `frame.executeJavaScript` (đúng cơ chế inspector đang dùng ở `electron/main/index.ts:3519-3543`) rồi chạy `axe.run(document)`. Kết quả trả về dạng JSON gọn, renderer chỉ hiển thị.

**Tech Stack:** axe-core (devDependency, bundle vào renderer), Electron IPC, React, node:test.

**Spec:** `pixelmind-feature-checklist-2dev.md:105` (D1-19).

## Global Constraints

- Dependency mới duy nhất: `axe-core` (devDependency — chỉ dùng để lấy file `axe.min.js`, không chạy ở Node).
- `electron/main/a11y.ts` **không** import `'electron'` (để test được). Nó nhận mảng frame `{ url, executeJavaScript }`.
- Không được trả `ok: true` khi không quét được frame nào hoặc injection lỗi. UI phải phân biệt "0 lỗi" với "không quét được".
- Giới hạn payload: tối đa 200 node/vi phạm, 20 node/vi phạm để IPC không nổ.
- Mirror API ở 3 chỗ: `shared/api.ts`, `electron/preload/index.ts`, `src/lib/mock.ts`.

## Review Focus

- Preview chưa chạy (không có iframe http/https) → `reason: 'no-frame'`, không phải "không có lỗi".
- Trang preview có CSP/meta chặn script → `reason: 'blocked'` + thông điệp, không crash dialog.
- Nhiều iframe (MultiPageCanvas) → quét đúng frame của `previewUrl`, không quét nhầm.
- axe chạy lại 2 lần liên tiếp → không nhân đôi kết quả (luôn là kết quả mới, thay thế state).
- Selector hiển thị được cả khi node nằm sâu trong shadow DOM (`target` là mảng).

```ts
export const A11Y_TAGS = ['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa', 'best-practice']
export const MAX_NODES_PER_VIOLATION = 20

const IMPACTS: A11yImpact[] = ['critical', 'serious', 'moderate', 'minor']

export function summarizeA11y(violations: A11yViolation[]) {
  const counts: Record<A11yImpact, number> = { critical: 0, serious: 0, moderate: 0, minor: 0 }
  for (const v of violations) counts[v.impact] += 1
  return { counts, total: violations.length }
}

export function emptyA11yResult(reason: A11yScanResult['reason'], error?: string): A11yScanResult {
  return {
    ok: false, reason, error, scannedAt: Date.now(), violations: [],
    counts: { critical: 0, serious: 0, moderate: 0, minor: 0 }, total: 0,
  }
}

const trimUrl = (url: string) => url.split('?')[0].replace(/\/+$/, '') || '/'

export function pickA11yFrameIndex(frames: Array<{ url: string }>, previewUrl?: string | null): number {
  if (frames.length === 0) return -1
  if (previewUrl) {
    const wanted = trimUrl(previewUrl)
    const index = frames.findIndex((f) => trimUrl(f.url || '') === wanted)
    if (index !== -1) return index
  }
  const httpIndex = frames.findIndex((f) => /^https?:/i.test(f.url || ''))
  return httpIndex === -1 ? 0 : httpIndex
}

/**
 * Script chạy TRONG frame preview. Trả object thuần JSON để IPC serialize được.
 * `axe` do main process nạp trước bằng executeJavaScript(axeSource).
 */
export function buildAxeRunScript(): string {
  return `(function () {
    if (typeof axe === 'undefined' || typeof axe.run !== 'function') {
      return { ok: false, reason: 'blocked', error: 'axe-core chưa được nạp vào trang xem trước.' };
    }
    var IMPACTS = ['critical','serious','moderate','minor'];
    return axe.run(document, {
      runOnly: { type: 'tag', values: ${JSON.stringify(A11Y_TAGS)} },
      resultTypes: ['violations']
    }).then(function (results) {
      return {
        ok: true,
        violations: (results.violations || []).map(function (v) {
          return {
            id: String(v.id), impact: IMPACTS.indexOf(v.impact) === -1 ? 'minor' : v.impact,
            help: String(v.help || ''), description: String(v.description || ''),
            helpUrl: String(v.helpUrl || ''), tags: v.tags || [],
            nodes: (v.nodes || []).slice(0, ${MAX_NODES_PER_VIOLATION}).map(function (n) {
              var target = n.target;
              return {
                selector: Array.isArray(target) ? target.join(' ') : String(target || ''),
                html: String(n.html || ''),
                failureSummary: String(n.failureSummary || '')
              };
            })
          };
        })
      };
    }).catch(function (err) {
      return { ok: false, reason: 'blocked', error: String((err && err.message) || err) };
    });
  })()`
}
```

Không import `electron`. Logic:

```ts
export async function runA11yScan(frames, axeSource, previewUrl) {
  if (!axeSource || typeof axeSource !== 'string') {
    return emptyA11yResult('failed', 'Không tải được axe-core trong ứng dụng.')
  }
  const index = pickA11yFrameIndex(frames, previewUrl)
  if (index === -1) return emptyA11yResult('no-frame', 'Chưa có khung xem trước nào đang mở.')
  const frame = frames[index]
  try {
    await frame.executeJavaScript(axeSource)
    const raw = (await frame.executeJavaScript(buildAxeRunScript())) as
      | { ok?: boolean; reason?: string; error?: string; violations?: unknown[] }
      | null
    if (!raw || raw.ok !== true || !Array.isArray(raw.violations)) {
      return { ...emptyA11yResult('blocked', raw?.error || 'Trang xem trước không trả về kết quả axe.'), frameUrl: frame.url }
    }
    const violations = raw.violations as A11yViolation[]
    const safe = violations
      .filter((v) => v && typeof v.id === 'string' && Array.isArray(v.nodes))
      .slice(0, 200)
      .map((v) => ({
        ...v,
        impact: (['critical', 'serious', 'moderate', 'minor'] as const).includes(v.impact as any) ? v.impact : 'minor',
        nodes: v.nodes.slice(0, MAX_NODES_PER_VIOLATION),
      })) as A11yViolation[]
    const { counts, total } = summarizeA11y(safe)
    return { ok: true, frameUrl: frame.url, scannedAt: Date.now(), violations: safe, counts, total }
  } catch (error: any) {
    return { ...emptyA11yResult('blocked', String(error?.message || error)), frameUrl: frame.url }
  }
}
```
